# Adhome website refinement

- Create a sticky desktop and mobile navigation, cinematic tiramisu introduction, editorial product collections, verified reviews, gifting, brand story, gallery, location details, final call-to-action, and minimal footer.

## Visual direction
- Establish an editorial luxury-food system using deep chocolate, espresso, cream, ivory, caramel, and restrained berry accents.
- Pair a high-contrast serif display face with a clean sans-serif body face.
- Generate cohesive close-up dessert and packaging photography, with restrained grain, image reveals, hover zoom, and subtle hero movement.
- Keep layouts spacious and asymmetrical, with the Classic Tiramisu as the signature product.

## Interaction and responsive behavior
- Add smooth scrolling, section-aware navigation, a polished mobile menu, scroll-reactive navigation, and restrained reveal motion that respects reduced-motion preferences.
- Make verified phone, directions, and ordering actions prominent and functional; ordering will use the provided phone number because no ordering URL was supplied.
- Present the Instagram follow control without inventing an account URL.
- Verify the page visually at desktop and mobile sizes, including navigation and primary actions.

## Technical details
- Define all palette, typography, texture, shadows, and motion through the central design system.
- Keep the single promotional experience at `/` with unique Adhome metadata.
